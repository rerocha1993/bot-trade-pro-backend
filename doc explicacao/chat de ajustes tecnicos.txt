🧠 Resumo técnico: Como os Pontos Institucionais são criados no sistema?
Os Pontos Institucionais são suportes e resistências técnicos validados por indicadores profissionais e gravados em banco de dados para serem utilizados por bots e exibidos no gráfico.

✅ 1. QUEM cria os pontos?
Os seguintes indicadores avançados têm autoridade para detectar e criar Pontos Institucionais:

VWAP

TPO (Volume Profile)

Order Flow

Order Block

(Futuramente: Institucional Trap, Absorções, etc.)

Eles fazem isso através da chamada ao método centralizado:

python
Copiar
Editar
PontoInstitucionalService.registrar_ponto(bot, tipo, preco, status, origem)
✅ 2. ONDE são criados no código?
Dentro do módulo core/, cada indicador (ex: vwap.py, tpo.py) avalia o candle atual ou estrutura histórica e, ao encontrar um ponto válido, chama o serviço para gravar o ponto.

O serviço salva no banco de dados na tabela pontos_institucionais, com os seguintes campos:

Campo	Tipo	Significado
id	PK	ID único do ponto
par	string	Ex: BTCUSDT
exchange	string	Ex: bybit
preco	float	Preço da zona (ex: 67894.22)
tipo	string	suporte ou resistencia
status	string	ativo, testado, rompido
origem	string	Ex: vwap, order_flow, tpo, etc
timestamp	datetime	Data/hora da detecção

✅ 3. QUANDO os pontos são criados?
A cada candle novo (ou intervalo de análise), os indicadores são processados.

Se algum critério técnico for atingido, o ponto é criado.

Exemplo (VWAP):

python
Copiar
Editar
if candle.fecha abaixo de VWAP e rompe banda -2σ:
    registrar_ponto(bot, "suporte", preco=VWAP, status="ativo", origem="vwap")
✅ 4. COMO os pontos são mantidos?
A cada candle, o sistema:

Atualiza o status dos pontos existentes:

Se o preço encosta no ponto: vira testado

Se ultrapassa com folga: vira rompido

Remove pontos antigos (se configurado), ou mantém no histórico.

✅ 5. COMO isso se conecta com a estratégia?
Antes de o bot decidir entrar em uma operação, o StrategyEngine consulta o serviço:

python
Copiar
Editar
pontos = PontoInstitucionalService.buscar_por_par_e_exchange(par, exchange)
E aplica lógicas como:

“Só entrar se estiver próximo de um suporte ativo.”

“Evitar operações se resistência foi testada duas vezes.”

class VWAPCalculator:
    def __init__(self, ohlcv):
        self.ohlcv = ohlcv
        self.prices = [float(c[4]) for c in ohlcv if c and len(c) >= 5]  # Fecha
        self.volumes = [float(c[5]) for c in ohlcv if c and len(c) >= 6]

        self.lows = [float(c[3]) for c in ohlcv if c and len(c) >= 4]

    def vwap(self, anchor_idx=0):
        # Proteção: OHLCV precisa ter pelo menos 1 candle válido
        if not self.ohlcv or len(self.prices) == 0 or len(self.volumes) == 0:
            return None
        total_volume = 0
        total_pv = 0
        for i in range(anchor_idx, len(self.ohlcv)):
            close = float(self.ohlcv[i][4])
            vol = float(self.ohlcv[i][5])
            total_volume += vol
            total_pv += close * vol
        if total_volume == 0:
            return None
        vwap_val = total_pv / total_volume
        # NOVO: Validação do range
        max_high = max(self.highs) if self.highs else None
        min_low = min(self.lows) if self.lows else None
        if max_high is not None and min_low is not None:
            if not (min_low <= vwap_val <= max_high):
                # VWAP anômalo, não retorna valor fora do range
                return None
        return vwap_val

class VWAPCalculator:
    def __init__(self, ohlcv):
        self.ohlcv = ohlcv
        self.prices = np.array([c[4] for c in ohlcv])  # Preço de fechamento
        self.volumes = np.array([c[5] for c in ohlcv])  # Volume

        volumes = self.volumes[anchor_idx:]
        if np.sum(volumes) == 0:
            return None
        vwap_value = np.sum(prices * volumes) / np.sum(volumes)
        # Validação: VWAP dentro do range dos candles do período
        max_high = np.max(self.highs[anchor_idx:]) if len(self.highs) else None
        min_low = np.min(self.lows[anchor_idx:]) if len(self.lows) else None
        if max_high is not None and min_low is not None:

        if vwap_value is None:
            return None
        prices = self.prices[anchor_idx:]
        volumes = self.volumes[anchor_idx:]
        desvios_out = {}
        mean = vwap_value
        variance = np.sum(volumes * (prices - mean)**2) / np.sum(volumes)
        stddev = np.sqrt(variance)
        max_high = np.max(self.highs[anchor_idx:]) if len(self.highs) else None
        min_low = np.min(self.lows[anchor_idx:]) if len(self.lows) else None
        for n in desvios:
            upper = vwap_value + n * stddev
            lower = vwap_value - n * stddev

import numpy as np

def volume_profile(ohlcv, bins=20, min_tolerancia=0.98, max_tolerancia=1.02):
    """
    Calcula LVN/HVN (Low/High Volume Nodes) do volume profile e retorna só zonas válidas.
    Retorna dicionário com zonas LVN/HVN dentro do range analisado.
    """
    closes = np.array([c[4] for c in ohlcv])
    volumes = np.array([c[5] for c in ohlcv])
    highs = np.array([c[2] for c in ohlcv])
    lows = np.array([c[3] for c in ohlcv])

    max_high = np.max(highs)
    min_low = np.min(lows)

    # Cria histograma de volumes por faixa de preço (volume profile)
    hist, edges = np.histogram(closes, bins=bins, weights=volumes)
    lvns = []
    hvns = []

    # Detecta nós de baixo volume (LVN) e alto volume (HVN)
    for i in range(1, len(hist) - 1):
        price = (edges[i] + edges[i + 1]) / 2
        if hist[i] < hist[i - 1] and hist[i] < hist[i + 1]:
            lvns.append(price)
        if hist[i] > hist[i - 1] and hist[i] > hist[i + 1]:
            hvns.append(price)

    # Validação: só aceita zonas dentro do range permitido
    limite_superior = max_high * max_tolerancia
    limite_inferior = min_low * min_tolerancia
    lvns_filtradas = [p for p in lvns if limite_inferior <= p <= limite_superior]
    hvns_filtradas = [p for p in hvns if limite_inferior <= p <= limite_superior]

    return {
        "LVN": lvns_filtradas,
        "HVN": hvns_filtradas,
        "range": [min_low, max_high]
    }

    def hvn_lvn(self, n=3, tolerancia=0.02):
        # HVN = bins com maior volume; LVN = bins com menor volume (> 0)
        idx_sort = np.argsort(self.hist)
        lvn_idx = idx_sort[:n]
        hvn_idx = idx_sort[-n:]

        # Adiciona filtro: só retorna zonas dentro do range do candle analisado
        max_limit = self.candle_max_high * (1 + tolerancia)
        min_limit = self.candle_min_low * (1 - tolerancia)

        lvns = [float(self.bin_labels[i]) for i in lvn_idx
                if min_limit <= self.bin_labels[i] <= max_limit]
        hvns = [float(self.bin_labels[i]) for i in hvn_idx
                if min_limit <= self.bin_labels[i] <= max_limit]

        return {
            "HVN": hvns,
            "LVN": lvns
        }

    def rejection_zones(self, min_vol=0.0, max_vol=0.05, tolerancia=0.02):
        # Price rejection = bins onde volume é muito baixo em relação ao total
        total_vol = np.sum(self.hist)
        percent_vol = self.hist / total_vol
        max_limit = self.candle_max_high * (1 + tolerancia)
        min_limit = self.candle_min_low * (1 - tolerancia)
        return [float(self.bin_labels[i]) for i, pct in enumerate(percent_vol)
                if min_vol < pct < max_vol and min_limit <= self.bin_labels[i] <= max_limit]

    def top_volume_zones(self, pct=0.7, tolerancia=0.02):
        # Retorna zonas que acumulam X% do volume (zona de valor institucional)
        total = np.sum(self.hist)
        idx_sort = np.argsort(self.hist)[::-1]  # maior para menor
        cumul = 0
        area = []
        max_limit = self.candle_max_high * (1 + tolerancia)
        min_limit = self.candle_min_low * (1 - tolerancia)
        for i in idx_sort:
            price = float(self.bin_labels[i])
            if min_limit <= price <= max_limit:
                cumul += self.hist[i]
                area.append(price)
                if cumul / total >= pct:
                    break
        return sorted(area)

    def price_signal(self, preco_atual, tolerancia=0.02):
        nodes = self.hvn_lvn(tolerancia=tolerancia)

        return {"acao": "hold", "motivo": "Sem trigger profile"}

    def export_heatmap(self):

class OrderBlockDetector:
    def __init__(self, ohlcv: list):
        """
        ohlcv: lista de candles no formato [timestamp, open, high, low, close, volume]
        """
        self.ohlcv = ohlcv
        # range dos candles para filtro de validação
        self.highs = [c[2] for c in ohlcv]
        self.lows = [c[3] for c in ohlcv]
        self.max_high = max(self.highs)
        self.min_low = min(self.lows)
        self.tolerancia = 0.02  # 2%

    def identificar_blocks(self, tipo='bullish'):
        """
        tipo: 'bullish' ou 'bearish'
        Retorna uma lista com os candles identificados como blocos institucionais.
        """
        blocks = []

        for i in range(len(self.ohlcv) - 2):
            atual = self.ohlcv[i]
            prox = self.ohlcv[i + 1]

            open_atual, close_atual = atual[1], atual[4]
            high_atual, low_atual = atual[2], atual[3]
            open_prox, close_prox = prox[1], prox[4]

            if tipo == 'bullish':
                # Último candle vermelho seguido por verde forte
                if close_atual < open_atual and close_prox > open_prox and close_prox > close_atual:
                    zona = (open_atual, high_atual)
                    # Validação institucional: zona deve estar no range dos candles analisados
                    if self._zona_valida(zona):
                        blocks.append({
                            'index': i,
                            'tipo': 'bullish',
                            'zona': zona
                        })

            elif tipo == 'bearish':
                # Último candle verde seguido por vermelho forte
                if close_atual > open_atual and close_prox < open_prox and close_prox < close_atual:
                    zona = (open_atual, low_atual)
                    if self._zona_valida(zona):
                        blocks.append({
                            'index': i,
                            'tipo': 'bearish',
                            'zona': zona
                        })

        return blocks

    def _zona_valida(self, zona):
        """Só aceita blocks institucionais dentro do range dos candles do período analisado."""
        min_limit = self.min_low * (1 - self.tolerancia)
        max_limit = self.max_high * (1 + self.tolerancia)
        return all(min_limit <= preco <= max_limit for preco in zona)

import numpy as np
from scipy.signal import find_peaks

class ElliottDetector:
    def __init__(self, prices):
        self.prices = np.array(prices)
        self.max_price = float(np.max(self.prices)) if len(self.prices) else None
        self.min_price = float(np.min(self.prices)) if len(self.prices) else None
        self.tolerancia = 0.02  # 2%

    def detectar_picos_vales(self, distance=5):
        peaks, _ = find_peaks(self.prices, distance=distance)
        troughs, _ = find_peaks(-self.prices, distance=distance)

        # Validação: só aceita picos/vales dentro do range institucional (máx/mín dos preços, com tolerância)
        max_limit = self.max_price * (1 + self.tolerancia) if self.max_price is not None else None
        min_limit = self.min_price * (1 - self.tolerancia) if self.min_price is not None else None

        peaks_filtrados = [idx for idx in peaks if min_limit <= self.prices[idx] <= max_limit]
        troughs_filtrados = [idx for idx in troughs if min_limit <= self.prices[idx] <= max_limit]
        return peaks_filtrados, troughs_filtrados

    def estrutura_onda_simples(self):
        peaks, troughs = self.detectar_picos_vales()
        estrutura = {
            'impulsivas': peaks,
            'corretivas': troughs
        }
        return estrutura

    def validar_estrutura_basica(self):
        estrutura = self.estrutura_onda_simples()
        if len(estrutura['impulsivas']) >= 3 and len(estrutura['corretivas']) >= 2:
            return True, estrutura
        return False, estrutura

# Arquivo: core/fibonacci.py

class Fibonacci:
    def __init__(self, high: float, low: float):
        self.high = high
        self.low = low
        self.levels = self.calcular_niveis()
        self._validar_niveis()

    def calcular_niveis(self):
        diff = self.high - self.low
        return {
            '0.0%': round(self.low, 2),
            '23.6%': round(self.low + 0.236 * diff, 2),
            '38.2%': round(self.low + 0.382 * diff, 2),
            '50.0%': round(self.low + 0.5 * diff, 2),
            '61.8%': round(self.low + 0.618 * diff, 2),
            '78.6%': round(self.low + 0.786 * diff, 2),
            '100.0%': round(self.high, 2),
            '161.8%': round(self.low + 1.618 * diff, 2),
            '261.8%': round(self.low + 2.618 * diff, 2)
        }

    def _validar_niveis(self):
        """Garante que todos os níveis fiquem dentro do range institucional."""
        # Tolerância para aceitar levemente fora do range, ex: extensões de alvo
        max_limit = self.high * 1.02
        min_limit = self.low * 0.98
        # Só mantém níveis dentro do range permitido, exceto extensões (161.8%, 261.8%)
        for k, v in list(self.levels.items()):
            if k in ('161.8%', '261.8%'):
                continue  # Permite extensões além do topo
            if not (min_limit <= v <= max_limit):
                del self.levels[k]

    def exibir_niveis(self):
        print("Níveis de Fibonacci:")

    def _validar_sl_tp(self, resultado):
        """Só retorna SL/TP se estiverem dentro do range institucional, ou retorna None."""
        # Permite TP > high se for extensão, mas nunca aceita SL/TP negativos ou fora do range extremo
        sl, tp = resultado.get("sl"), resultado.get("tp")
        max_limit = self.high * 1.02
        min_limit = self.low * 0.98
        if sl is not None and not (min_limit <= sl <= max_limit):
            resultado["sl"] = None
        if tp is not None and tp < 0:
            resultado["tp"] = None
        return resultado

import numpy as np

class OrderFlowAnalyzerPro:
    def __init__(self, order_book, trades, ohlcv):
        self.order_book = order_book
        self.trades = trades
        self.ohlcv = ohlcv
        # Range institucional para validação de zonas
        self.highs = [c[2] for c in ohlcv] if ohlcv else []
        self.lows = [c[3] for c in ohlcv] if ohlcv else []
        self.max_high = max(self.highs) if self.highs else None
        self.min_low = min(self.lows) if self.lows else None
        self.tolerancia = 0.02

    def calcular_delta_candle(self, candle_trades):
        buy_vol = sum(t['qty'] for t in candle_trades if t['side'] == 'buy')
        sell_vol = sum(t['qty'] for t in candle_trades if t['side'] == 'sell')
        delta = buy_vol - sell_vol
        return delta

    def detectar_absorcao(self, price_level, trades, min_qty=10):
        vol_agressor = sum(t['qty'] for t in trades if t['price'] == price_level)
        if vol_agressor >= min_qty and self._preco_valido(price_level):
            return True
        return False

    def clusterizar_volume(self, price_range=None):
        volumes = {}
        for t in self.trades:
            p = t['price']
            if price_range and not (price_range[0] <= p <= price_range[1]):
                continue
            if not self._preco_valido(p):
                continue
            volumes[p] = volumes.get(p, 0) + t['qty']
        clusters = sorted(volumes.items(), key=lambda x: -x[1])
        return clusters[:10]

    def analisar(self):
        if not self.ohlcv or not self.trades:
            return {"acao": "hold", "motivo": "Sem dados de orderflow"}

        ultimo_candle = self.ohlcv[-1]
        candle_start = ultimo_candle[0]
        candle_end = ultimo_candle[0] + 60 * 1000  # 1min em ms

        candle_trades = [t for t in self.trades if candle_start <= t['timestamp'] < candle_end]

        delta = self.calcular_delta_candle(candle_trades)
        clusters = self.clusterizar_volume()
        maior_cluster = clusters[0][0] if clusters else None

        absorcao = self.detectar_absorcao(maior_cluster, candle_trades) if maior_cluster else False

        if delta > 0 and absorcao:
            return {"acao": "buy", "motivo": f"Delta+ Absorção em {maior_cluster}"}
        elif delta < 0 and absorcao:
            return {"acao": "sell", "motivo": f"Delta- Absorção em {maior_cluster}"}
        elif delta > 0:
            return {"acao": "buy", "motivo": f"Delta positivo: {delta}"}
        elif delta < 0:
            return {"acao": "sell", "motivo": f"Delta negativo: {delta}"}
        else:
            return {"acao": "hold", "motivo": "Order Flow neutro"}

    def _preco_valido(self, preco):
        """Só aceita preço de zona/order flow dentro do range institucional."""
        if self.max_high is None or self.min_low is None:
            return True  # Se range não disponível, não filtra
        min_limit = self.min_low * (1 - self.tolerancia)
        max_limit = self.max_high * (1 + self.tolerancia)
        return min_limit <= preco <= max_limit

from core.conexoes.conexao_bybit import BybitConnector

class ExecutorReal:
    def __init__(self, par, modo_execucao='simulador'):
        self.par = par.replace("/", "")
        self.modo_execucao = modo_execucao  # 'real' ou 'simulador'
        self.bybit = BybitConnector(modo_execucao=modo_execucao).exchange

    def executar_ordem(self, direcao, quantidade, preco_entrada=None, stop_loss=None, take_profit=None):
        tipo_ordem = 'limit' if preco_entrada else 'market'
        params = {}
        if tipo_ordem == 'limit':
            params['price'] = preco_entrada
            params['timeInForce'] = 'PostOnly'

        # Agora sempre envia, não importa se 'real' ou 'simulador'
        try:
            ordem = self.bybit.create_order(
                symbol=self.par,
                type=tipo_ordem,
                side=direcao,
                amount=quantidade,
                params=params
            )
            print("✅ Ordem executada:", ordem)
        except Exception as e:
            print("❌ Erro ao executar ordem:", e)
            return

        # STOP LOSS
        if stop_loss:
            try:
                sl = self.bybit.create_order(
                    symbol=self.par,
                    type='stop_market',
                    side='sell' if direcao == 'buy' else 'buy',
                    amount=quantidade,
                    params={'stopPrice': stop_loss}
                )
                print("✅ SL ativado:", sl)
            except Exception as e:
                print("❌ Erro no SL:", e)

        # TAKE PROFIT
        if take_profit:
            try:
                tp = self.bybit.create_order(
                    symbol=self.par,
                    type='take_profit_market',
                    side='sell' if direcao == 'buy' else 'buy',
                    amount=quantidade,
                    params={'stopPrice': take_profit}
                )
                print("✅ TP ativado:", tp)
            except Exception as e:
                print("❌ Erro no TP:", e)
